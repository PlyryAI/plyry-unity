# Quick Start sample

1. Add PlyryClient and PlyryRuntimePanel to a scene object.
2. Add PlyryGenerationTarget to a game object players can customize.
3. Add PlyryQuickStart to the panel object and assign that target.
4. Press Play, sign in or create a Plyry account, then generate.

The PlyryClient default service URL is https://plyry.com. The sample opens the runtime panel when the scene starts.
